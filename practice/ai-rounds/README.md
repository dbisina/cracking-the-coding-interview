# AI-Round Practice Projects

These are multi-file projects for practising AI-assisted coding interviews (Module 21). Each one follows the reported Meta format: **fix a bug → build a feature → scale it up**, in 60 minutes, with a chat-only AI assistant.

| Project | Core skills |
|---|---|
| `maze-router/` | BFS state design, grid constraints, reverse search |
| `word-packer/` | backtracking, bitmasks, branch and bound |
| `build-order/` | topological sort, cycle detection, iterative algorithms at scale |

They're in Python, which Meta allows alongside Java, C++, C#, Kotlin and TypeScript. The tutor can port a project to your language on request.

**Learners:** open only the project's top-level files. Everything under `tutor/` (stage briefs, hidden tests, reference solutions) is for the tutor.

**Tutor:** see `curriculum/21-ai-assisted-coding.md` and `AGENTS.md` §5.2.
