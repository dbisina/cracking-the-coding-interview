# Maze Router (AI-round practice)

You've inherited the router for a warehouse robot. The robot moves up, down, left or right on a grid map and can't pass through walls.

```
grid.py         map model and parser
router.py       route finding
main.py         CLI entry point
test_router.py  tests
```

Run the tests:

```bash
python -m pytest -q
```

Your interviewer gives you the tasks one stage at a time. An AI assistant is available in chat. It can read the code, but you make every edit yourself.

**Don't open `tutor/`.** It holds the interviewer's notes and the hidden tests.
